# Tumeni Vibe Lanes

Build a complete, interactive Progressive Web App (PWA) for "tumeni." using the attached UI mockup screenshots as your strict visual and design reference.

1. VISUAL & DESIGN MATCHING (CRITICAL):

- Match the exact aesthetic, colors, spacing, and typography from the attached screenshots: Deep Obsidian Black background (#0A0A0C), Charcoal Slate cards (#141418) with thin #222228 borders, and Vibrant Amber Gold accents (#FFB800).
- Use the exact "tumeni." logo mark shown in the attached login screen (the incomplete white circle ring with the overlapping speech bubble and the glowing amber gold dot).
- Keep the exact bottom floating glassmorphism navigation bar and top lane-switcher pill design shown in the screenshots.

2. UPGRADE FROM "MUSIC-ONLY" TO FULL MIXED-MEDIA SOCIAL APP:

- While copying the visual design of the screenshots, make the content versatile like a real modern social app—not just a music player.
- The 4 Vibe Lanes (`My Circle`, `Music`, `Laughs`, `Mix`) must filter a rich, multi-format feed containing:
  - Short vertical video clips (with play icons, view counts, and creator handles).
  - Funny text thoughts and image memes (for the `Laughs` lane).
  - Music & audio snippets (with the glowing gold waveform bar from the screenshot).
- On the Profile screen, match the top header and the 2x2 stat cards (`TAP-INS`, `CO-SIGNS`, `SAVED`, and the VIP `CREW PASSES` card) from the screenshot, but display a 3-column mixed-media grid (videos, photos, and audio) at the bottom instead of just a list of songs.

3. WORKING TEST AUTHENTICATION (START SCREEN):

- Start on the Welcome/Sign-In screen matching the attached login mockup.
- Include working test options: "Continue with Google", a Phone Number input field, and an Email input field.
- Make sure entering ANY test phone number or email (or clicking Google) immediately logs the user in and transitions smoothly into the Home Feed so I can test the full app flow right away.

4. FULL INTERACTIVITY:

- Make every tab, lane pill, "SEND IN" share button (opening a quick-share drawer to send posts into "The Crew" chat), "+" Create Post modal (supporting Video, Photo, Audio, and Text drops that publish live to the feed), and the Messages/Crew Chat screens fully clickable and functional with realistic dummy data. Include rich additional touches like sound waveform animations, interactive like and comment counts, and quick profile switching.
